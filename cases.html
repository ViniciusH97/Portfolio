01 API SECURITY · PROJETO ACADÊMICO

Análise de vulnerabilidades na API crAPI

Trabalho de conclusão de curso sobre pentesting em APIs RESTful, baseado no OWASP e em uma aplicação deliberadamente vulnerável para treinamento.

Contexto

Aplicação de treinamento usada para estudar riscos específicos de APIs e controles de acesso.

Prática

Reconhecimento, análise de endpoints, validação controlada de hipóteses e documentação de evidências.

Referências

OWASP API Security, autenticação, autorização, exposição de dados e validação de entradas.

Aprendizado

Conectar uma falha técnica ao impacto observável e a uma recomendação de correção.
