Five findings were recorded during an assessment of a financial application in a staging environment: one high, one medium, and three informational.

The primary demonstrative risk was an authorization flaw between user contexts that could allow improper access to another user's resources. A session exposure window after logout was also observed. The remaining items concerned reconnaissance, interface consistency, and input handling.

F-04 · HIGHACCESS CONTROL

Authorization flaw between user contexts

The application did not sufficiently validate the relationship between the authenticated user and a wallet/resource identifier supplied in the request.

Impact

An authenticated user could attempt to access resources associated with another context, affecting confidentiality and the integrity of permitted operations.

Recommendation

Validate the relationship between identity, requested resource, and contextual authorization on the server for every request. Never trust client-supplied identifiers.

F-02 · MEDIUMSESSION MANAGEMENT

Session tokens remain valid after logout

After logout, a previously issued token remained accepted during its configured validity window.

Impact

If a session is compromised before logout, an attacker may retain access to authorized resources until effective expiration or revocation.

Recommendation

Adopt token revocation or rotation, invalidate refresh tokens on logout, and review TTLs according to the risk of each operation.

F-01 · F-03 · F-05INFORMATIONAL

Additional observations

F-01

Interfaces before authentication

Screens could render before login, although back-end services maintained access controls. Restrict rendering while keeping server-side protection mandatory.

F-03

Front-end inconsistency

A conversion/display issue was observed in one interface area. Apply consistent type handling and tests for unexpected responses.

F-05

Malformed input

Invalid parameters caused an unhandled error response. Apply input validation and controlled responses without internal details.
